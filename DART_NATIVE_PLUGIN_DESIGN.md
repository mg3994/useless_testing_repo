# DartNative Camera & Overlay Plugin Architecture Design

## Overview
This document outlines the architecture for building an advanced **DartNative Plugin** (`dartnative_camera`), mimicking DartNative plugin conventions (`dn plugin build`).

### Core Design Philosophy
- **Native UI & Hardware Layer (Android/iOS)**: CameraX preview & video recording, GPU-accelerated Media3 texture overlays (`ParallelogramSpan`, live badges, timers, scores, penalties), and hardware video encoding.
- **Dart Business Logic Layer**: Network socket streams (`http://185.48.228.171:21741`), business rules, state parsing (`InfoModel`, `RealtimeModel`, `RiderModel`, `HorseModel`, `FinalModel`), and direct JNI invocation.
- **DartNative JNI Runtime**: Direct C/JNI bindings bypassing standard Flutter MethodChannels for ultra-low latency native object bridge and zero-copy state synchronization.

## Plugin Package Structure (`dartnative_camera.aar`)

The closed-distribution or compiled DartNative plugin artifact structure relies on exposing the prebuilt `.aar` as the Gradle artifact, while explicitly re-declaring transitive Maven dependencies:

```groovy
// GENERATED by `dn plugin build` — do not edit.
//
// Closed-distribution Android wrapper: exposes the prebuilt dartnative_camera.aar as this
// Gradle project's artifact so the dn plugin loader can include this directory
// exactly like a source plugin module. The .aar carries the compiled classes +
// JNI libraries; its external Maven dependencies are re-declared below (an
// .aar has no POM) so they resolve transitively on the app's classpath.
configurations.maybeCreate('default')
artifacts.add('default', file('dartnative_camera.aar'))
dependencies {
    add('default', 'androidx.camera:camera-core:1.3.0-beta01')
    add('default', 'androidx.camera:camera-camera2:1.3.0-beta01')
    add('default', 'androidx.camera:camera-lifecycle:1.3.0-beta01')
    add('default', 'androidx.camera:camera-video:1.3.0-beta01')
    add('default', 'androidx.camera:camera-view:1.3.0-beta01')
    add('default', 'androidx.media3:media3-effect:1.2.0')
    add('default', 'com.google.guava:guava:32.0.1-android')
    add('default', 'androidx.core:core-ktx:1.12.0')
    add('default', 'androidx.annotation:annotation:1.7.1')
    add('default', 'androidx.lifecycle:lifecycle-common:2.7.0')
    add('default', 'androidx.lifecycle:lifecycle-runtime:2.7.0')
    add('default', 'androidx.lifecycle:lifecycle-process:2.7.0')
}
```

## DartNative JNI Direct Binding Methods

The native bridge in `ch.zeitmessungen.equestre.plugin.DartNativeCameraBridge` exposes JNI entrypoints (`@Keep` annotated) callable directly from Dart via DartNative dynamic invocation (`invokeNative` / `dartnative` runtime):

| Native JNI Signature | Description |
|----------------------|-------------|
| `nativeUpdateOverlayData(String rider, String horse, String horseNum, String penalties, String time, String rank, String gap, boolean isLive)` | Directly pushes updated display fields from Dart into native Media3 GPU texture overlays. |
| `nativeSetOverlayVisibility(String key, boolean visible)` | Controls overlay component visibility flags in real time. |
| `nativeStartRecording(String outputPath)` | Triggers native CameraX video capture recording. |
| `nativeStopRecording()` | Stops active video capture recording. |

## Native Hardware Rendering Flow

```
┌──────────────────────────────────────────────┐
│        DART BUSINESS LOGIC (Flutter)         │
│  - Socket.IO stream & State updates         │
└──────────────────────┬───────────────────────┘
                       │ Direct DartNative JNI
┌──────────────────────▼───────────────────────┐
│     DartNativeCameraBridge (Kotlin / JNI)    │
│  - Updates OverlayDataProvider state         │
└──────────────────────┬───────────────────────┘
                       │
┌──────────────────────▼───────────────────────┐
│     NATIVE CAMERAX & MEDIA3 EFFECT UI        │
│  - PreviewView surface                       │
│  - Media3 TextureOverlay (ParallelogramSpan) │
│  - Output MP4 Video File                     │
└──────────────────────────────────────────────┘
```
